# Battle Replay presentation policy

James's 4 October 2026 instruction replaces the earlier guidance to show question marks for visible copy ambiguity. Prefer a concrete, well-supported board when the recorded game admits several possibilities. The game rules in `battle-replay-rules.md` still govern reconstruction.

## Facts and best guesses

- Confirmed facts come from the source, verified game rules and card text. Later evidence corrects earlier frames only where the fact was already true.
- A best guess selects one complete surviving history for a modeled source interval. Damage, position, attachments and evolution stacks stay correlated along that history. It does not establish physical identity or printing proof.
- Hidden information stays hidden: opponent hand faces, face-down Prizes, deck order and unnamed draws. Known counts remain numeric.

Hard evidence always takes priority. A preference cannot remove a viable factual alternative, override a known value, change the saved Battle Log or enter statistics. Probable artwork or HP never proves a physical card's identity.

## Choosing a history

Prefer source-compatible histories using named, deterministic policies. An observed attack knockout-listing convention may rank alternatives, but is an empirical preference rather than a game rule. Limit it to supported same-owner batches immediately following an attack that names the Active Pokémon; a clear counterexample disables it for that log. Its disabled form must preserve all confirmed facts.

Use compatible printing families already witnessed for the same player as a display preference. Exact printing and native execution evidence take priority. A chosen history and its displayed HP must agree; unavailable modifier evidence is a reconstruction gap, not permission to present an incompatible maximum.

For ambiguous evolution, prefer a history that keeps the existing presentation slot before breaking remaining ties using source-derived creation order. This is a display preference, not proof of the evolved physical copy. Later proof may select another lineage; its damage, attachments and visual Bench slot must still stay together when native presentation IDs are remapped. Do not claim calibrated probabilities, count duplicated solver worlds as votes, infer strategic intent, or use match footage to select a runtime history.

An unmodeled operation or exhausted search bound is a gap. When the source proves an operation affects only a local domain, retain the surviving histories and references for unaffected cards and refresh the affected domain from its retained evidence. Select the complete display history after later evidence has narrowed those alternatives; a local gap must not lock an earlier guess that later proof can contradict. Global or overlapping uncertainty resets the affected history. Preserve recorded cards and counts, report the cause, and improve missing operation support rather than fabricating a transition.

An inferred evolution stack may allocate guaranteed pooled layers only by referencing existing native card objects. Consume each layer once, retain its printing evidence, and validate the complete group inventory. A name match alone cannot mint or replace a physical layer.

A fully certain, count-balanced factual board is a recovery checkpoint. Reconcile compatible surviving histories with its evidence. If an unsupported operation erased the modeled history, begin a new interval from that complete board rather than keeping stale symbolic cards. Do not back-fill a chosen history across an erased interval.

## Interface and verification

Show selected numbers plainly. Give best-guess cards accessible labels and an explanation in their preview, with one expandable summary for the current board. Avoid repeated qualifiers that change card alignment. Keep unsupported reconstruction gaps visible in diagnostics.

Measure confirmed corrections separately from best-guess coverage. Validate every materialized board against known fields and card conservation. Animations use amounts recorded by the current source operation, never differences caused by retrospective reassignment.

Use the original saved-game corpus and independent answer keys. Report preference ablations, deterministic outputs, selection and refusal causes, and remaining gaps. Match footage may independently test a frozen policy but never supplies compiler input or a card-specific rule.
