# Security Policy

Poke Notes takes security reports seriously. If you believe you have found a vulnerability, please report it privately and do not open a public issue with exploit details.

## How to Report

Send a concise report to the maintainers through the repository's private security channel or the project's usual private contact path.

Include:

- A short description of the issue
- Steps to reproduce
- The affected area or route
- Any proof of concept, logs, or screenshots

## What to Expect

- We will acknowledge the report as soon as we can, typically within 2 business days.
- We will work with the reporter to validate impact and plan a fix.
- Please keep details private until we confirm the issue is resolved.

## Scope Notes

This project uses Supabase Auth, Google OAuth, and environment-based configuration. Please avoid sharing secrets, tokens, or live account data in any report.
